## 3. 보내는 순서 제안 · 회신 기한
1. **공식 영상이 확인된 곳 먼저**: 락앤락(P2) → 아이프리 제조사(P3) → 글라스락(P2) → 올리빙(P1, 연락처부터 확인)
2. **연락 창구는 있으나 영상 미확인**: 실리쿡(메일) → 네오플램 → 락앤락 압축팩(P1, 1번과 한 번에 문의) → 필립스코리아 → 보만(코오롱몰)
3. **쇼핑몰 Q&A만 있는 곳**: 할메이드 → 리벤스 → 한샘몰 입점 판매자 → 아이프리홀딩스(제조사 회신이 없을 때만)
4. **창구 미확인**: 코멕스·트루비온은 공식 창구를 찾은 뒤 보냅니다

- 회신 기한은 **보낸 날부터 10일**로 잡습니다. 10일이 지나도 회신이 없으면 "무응답"으로 [실측 표 3장](./source-rights-survey.md#3-실측-표-제품--경로)에 적고 다음 대상으로 넘어갑니다(재촉은 1회만).
- 보낸 날·창구·회신 날짜를 3장 `대기 시간`에, 허락 회신 위치를 4장 `허락 증빙 위치`에 적습니다.
