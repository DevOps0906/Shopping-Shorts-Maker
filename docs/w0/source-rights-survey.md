# W0 권리 확인 원본 실측 기록 양식

작성 2026-11-11 · 작업: [task-002](../../tasks/task-002.md) · 근거: [기획서 3장 02](../planning.md#02-소스-모으기), [8장](../planning.md#8-리스크와-대응), [15-4](../planning.md#15-4-권리정책-점검), [17-2 D1](../planning.md#17-2-확정된-결정) · 결과 옮길 곳: [00_LEAN.md 결과](../00_LEAN.md)

실측과 연락은 사용자가 합니다. 이 문서는 빈칸을 채우는 양식입니다.

## 0. 지킬 것
- 권리 확인 전 원본은 내려받아 결과물에 쓰지 않습니다(D1). 자동 검색 결과는 연락할 대상을 찾는 참고용으로만 씁니다
- 허락은 글로 남는 회신(메일·판매자 문의 답변·DM 캡처)으로 받고, 증빙 위치를 4절 표에 적습니다
- 허락 범위가 애매하면 "확보"로 세지 않고 메모에 남깁니다. 범위 해석은 [전문가 검토 의뢰서](./legal-review-request.md)로 넘깁니다

## 1. 테스트 카테고리 3개 (2026-11-12 사용자 확정 · 판매 상품 확정 아님)

## 5. 사용 허락 요청 메시지 템플릿
`{ }`를 채워 보냅니다. 회신은 글로 받습니다. 허락 범위 문구는 [전문가 검토](./legal-review-request.md) 전 초안입니다.

### 5-1. 판매자·제조사용 (한국어)
```
안녕하세요, {채널명} 운영자 {이름}입니다.
{판매처}에서 판매 중인 {제품명}을 소개하는 숏폼 영상(YouTube Shorts 등)을 만들려고 합니다.
보유하신 제품 사용 영상을 아래 범위로 써도 될지 여쭙니다.

- 쓰는 곳: {채널 URL} (YouTube Shorts{, 기타 플랫폼})
- 쓰는 방식: 일부 구간을 잘라 세로(9:16)로 맞추고, 새 내레이션 음성과 자막을 덧입힙니다
- 화면 위 기존 자막·로고: {그대로 둠 / 가림·제거 허락 요청}
- 상업적 이용: 설명란에 제휴 구매 링크(예: 쿠팡 파트너스)가 들어가며, 제휴 사실을 고지합니다
- 출처 표기: {원하시는 표기 방식}
- 기간: {예: 게시 후 별도 요청 시 내림}

가능하시면 원본 파일(가장 높은 화질)을 {메일 주소}로 보내 주시거나 받을 수 있는 링크를 알려 주세요.
이 메시지에 "위 범위로 허락합니다"라고 회신해 주시면 기록으로 보관하겠습니다. 감사합니다.
```

### 5-2. 원작자(크리에이터)용 (한국어 · 영어) — W0에서는 쓰지 않음, 제품 안 허락 요청 안내 문안으로 보존
```
안녕하세요, {채널명}의 {이름}입니다. 올리신 영상({영상 URL})을 보고 연락드립니다.
이 영상의 일부를 {제품명} 소개 숏폼에 써도 될지 허락을 구합니다.
범위: 일부 구간 발췌·세로 크롭·새 음성과 자막 추가 / 설명란에 제휴 구매 링크 포함(제휴 고지함) / 출처 {표기 방식}으로 표기.
기존 자막·워터마크는 {그대로 둠 / 가림 허락 요청}.
허락하시면 원본 파일을 받을 방법을 알려 주시고, "허락합니다"라고 답장 부탁드립니다.
```
```
Hi, I'm {name} from {channel}. I found your video ({URL}).
May I use parts of it in a short product video about {product}?
Scope: clipped and cropped to 9:16, with new voice-over and captions; the description will include an affiliate purchase link (disclosed); credit as {credit format}.
Existing captions/watermark: {kept as is / permission requested to cover}.
If you agree, please reply "I permit this use" and let me know how to receive the original file. Thank you!
```
샤오홍슈 원작자용 중국어 문안: 미확인 — 필요하면 팀장 결정 후 추가합니다.
