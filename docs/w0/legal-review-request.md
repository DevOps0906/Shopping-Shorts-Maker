# 전문가(법률) 검토 의뢰서 초안 — AI 쇼핑숏츠 제작기

작성 2026-11-11 · 작업: [task-002](../../tasks/task-002.md) · 상태: 초안(미발송) · 발송은 사용자가 합니다.

이 문서는 질문 목록입니다. 아래 어떤 내용도 법률 판단이 아니며, 모든 쟁점은 "검토 요청" 상태입니다.

## 1. 의뢰 개요
| 항목 | 내용 |
|---|---|
| 서비스 | 쇼핑 상품 숏폼(9:16)을 소재 선정 → 원본 수집 → 대본 → AI 음성 → 편집 → 발행 6단계로 만드는 웹 도구 ([기획서 1장](../planning.md#1-개요), [3장](../planning.md#3-단계별-기능-명세)) |
| 현재 단계 | 출시 전 린 검증(W0). 법률 검토 전에는 자동 수집 영상을 "참고용·권리 미확인"으로 두고 편집에 쓰지 않기로 결정함([17-2 D1](../planning.md#17-2-확정된-결정)) |
| 받고 싶은 것 | 질문별 ① 가능 / 조건부 가능(조건) / 불가 의견 ② 서비스 설계에서 바꿔야 할 점 ③ 이용약관·동의 문구 수정안 |
| 준거 범위 | 한국 법 기준 + 해외 플랫폼(TikTok·샤오홍슈·YouTube) 약관. 해외 법 검토 필요 여부도 함께 의견 요청 |
| 회신 기한·비용 | 미확인 — 팀장 결정 필요 |
