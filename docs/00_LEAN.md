# 00 린 검증 — AI 쇼핑숏츠 제작기

작성 2026-11-11 · 근거: [기획서 9장](./planning.md#9-린-검증--수익화--로드맵--추천안), [17-2](./planning.md#17-2-확정된-결정) · 이 문서를 통과해야 MVP 작업(W1~W6)을 시작합니다.

| 항목 | 내용 |
| --- | --- |
| 문제 | 쇼핑 숏폼으로 제휴 수익을 내려는 개인 운영자는 소재 찾기, 원본 수집, 대본, 음성, 편집, 발행을 영상마다 손으로 반복해 1편에 오랜 시간이 걸립니다 |
| 고객 | 1순위: 쿠팡 파트너스 등으로 쇼핑 숏폼 채널을 1~3개 운영하거나 시작하려는 개인. 2순위: 쇼핑 숏폼 강사의 수강생 |
| 가설 | 쇼핑 숏폼 운영자는 강의 없이 도구만으로 편당 10분 안에 숏폼을 만들 수 있다면 월 구독료를 낼 것입니다(가격은 원가 측정 후 결정) |
| 대안(경쟁) | 고가 쇼핑 숏폼 강의(2,950,000원), 범용 편집 도구 수작업, 기존 n8n·텔레그램 봇 반자동 파이프라인 |
| 가장 싼 검증 | 프로토타입 화면으로 만든 랜딩페이지 + 사전예약 폼, 신청자에게 반자동 제작 대행 |
| 통과 기준 | ① 랜딩 방문 대비 사전예약 5% 이상 ② 제품 3종 중 2종 이상에서 권리 확인 원본 7편 확보(기획서 9장 검증 지표). 제품별 권리 확인 편수를 기록해 3편 예외 승인 하한도 함께 판단 ③ 대행 제작 편당 원가를 항목별로 측정 완료 |
| 기한·비용 | 2주. 비용은 광고비와 TTS·LLM 사용료만, 금액은 착수 시 정함 |
| 결과 | (검증 후 기록) 통과 / 보류 / 폐기 + 근거 |

**관련 작업**: [task-001](../tasks/task-001.md) 랜딩·사전예약 · [task-002](../tasks/task-002.md) 권리 확인 원본 실측·전문가 검토 의뢰 · [task-003](../tasks/task-003.md) 대행 파이프라인·원가 측정
