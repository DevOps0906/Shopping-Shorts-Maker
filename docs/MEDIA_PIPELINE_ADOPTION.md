# 미디어 파이프라인 적용 메모 (WhisperX · HyperFrames)

작성일 2026-11-20. 상태: **제안**. 공용 기획 정본: `platform-docs:products/_platform-core/MEDIA_PIPELINE.md`. 코드·의존성은 바꾸지 않았다.

## 현황

| 항목 | 내용 | 근거 |
|---|---|---|
| 편집 단계 | 컷 선택, 음성 합치기, 한 줄 자막, MP4 저장 | `docs/planning.md:138` |
| 영상 처리 | FFmpeg 워커 컨테이너, LGPL 빌드 | `docs/planning.md:783` |
| 미결 | GPL 도구(libx264)에도 GPL 거부 적용할지(ADR-0002) | `tasks/NOW.md:30` |
| STT | 없음(대본에서 음성을 만드는 흐름) | 전체 검색 결과 |

## 적용안

| ID | 내용 | 영향 | 선행 |
|---|---|---|---|
| S-1 | 05 편집 자막을 "한 줄 자막"에서 단어 단위 하이라이트로 확장 검토. 목소리(04) 결과 음성을 WhisperX로 정렬해 시각을 얻는다 | 05 편집 단계, 워커 | 스파이크 S1 |
| S-2 | 제품 가격·CTA(제휴 링크 문구) 오버레이를 HyperFrames 템플릿으로 만들 수 있는지 비교 | 05 편집 단계 | 스파이크 S2 |

참고: 음성을 TTS로 직접 만들기 때문에 대본 문장과 음성이 이미 1:1이다. 이 경우 정렬은 "받아쓰기"가 아니라 **강제 정렬**이므로 정확도 이득이 클 수 있다(가설, S1에서 확인).
