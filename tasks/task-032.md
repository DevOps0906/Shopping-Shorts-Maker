## 할 것
- Tauri 최신 stable(작업 시점 확인 후 버전 고정)로 `apps/desktop` 생성, ADR ⑤ 방식대로 운영 웹 주소를 여는 창, 탐색 허용 도메인은 우리 도메인만
- Windows 설치 파일(.msi 또는 .exe)·macOS(.dmg) 빌드, 코드 서명·공증(인증서·계정은 사용자 준비)
- 서명된 자동 업데이트(업데이트 서명 개인 키는 CI 비밀에만), 버전 표기
- 다운로드 페이지: 랜딩에 OS별 내려받기 버튼, 파일은 GitHub Releases 등 공개 저장소에
- 반응형 3구간은 웹 그대로, 창 최소 크기 1200(데스크톱 구간)

## 하지 않을 것
- 앱 안에 LLM·결제 키 넣기(키는 서버에만)
- 브라우저 확장 수집을 앱으로 대체
- 웹 화면 구조·토큰 변경

## 완료 조건 (실행 가능한 확인)
- [ ] CI에서 Windows·macOS 설치 파일 빌드 성공, 서명 검증 통과
