## 할 것
- manifest(MV3): `host_permissions`는 ADR 보강 ④ 목록만. 플랫폼 CDN 호스트는 구현 시 실측 후 확정하고 목록·근거를 이 파일에 추가. `externally_connectable`은 서비스 도메인 연결 페이지만
- `onMessageExternal`: `sender.origin`·`sender.url` 경로 고정, 그 외 무시
- 토큰 보관: 액세스는 `chrome.storage.session`, 갱신은 `chrome.storage.local`(제안, `팀장 결정 필요`). 401이면 1회 갱신 후 재시도
- 하트비트: `chrome.alarms` 30초, 응답의 대기 job으로 작업 시작(폴링 없음)
- 수집(D13 ①): 사용자가 연 틱톡·샤오홍슈 탭에서만, 사람 속도(요청·스크롤 간격 `팀장 결정 필요`), 1회 상한 = 4장 회차당 후보 수. 캡차·위험 제어 화면 감지 시 즉시 중단 → 사유를 서버에 보고(S-07 배너). 백그라운드 탭 생성·자동 수집 없음
- 목록 단계: 필드 허용 목록(URL·작성자·제목·길이·해상도·썸네일)만 추출·전송, platform·수집 시각은 보내지 않음
- 다운로드 단계(D13 ②): 플랫폼이 제공하는 **워터마크 포함 사본만**. 워터마크 없는 재생 사본(재생용 스트림 직접 추출) 금지, 얻을 수 없으면 "목록만" + 사유
- 업로드: 서버가 준 서명 URL로만, 파일 단위 스트림 전달(서비스 워커 수명 끊김 시 해당 파일만 재시도, 가능 범위는 구현 시 실측)
- 팝업: 연결 계정(이메일 일부)·연결 해제

## 하지 않을 것
- 쿠키·비밀번호·플랫폼 토큰 전송, `<all_urls>`·`cookies`·`webRequest` 권한, 원격 코드 로드, 배포(웹 스토어 여부는 task-028, 개발·베타는 수동 설치)
